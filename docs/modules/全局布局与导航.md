# 责任田：全局布局与导航

## 功能描述

负责后台应用的认证布局壳、侧边栏、顶部导航、用户入口、全局搜索入口和布局配置入口。

## 功能清单

- 认证布局：为 `_authenticated` 路由组提供统一页面框架。
- 侧边栏导航：展示主导航、分组导航、系统标识和用户信息入口。
- 顶部栏：承载搜索、主题切换、布局配置和用户信息入口。
- 用户入口：侧栏底部用户区域与顶部头像均直接跳转 `/settings`，不展示下拉菜单。
- 布局上下文：提供布局模式、侧边栏状态、搜索状态等横向能力。

## 入口与出口

- 入口：`src/routes/_authenticated/route.tsx` 装配认证布局。
- 出口：子路由通过 `Outlet` 渲染到布局内容区。

## API 明细

- 暂无真实 API，当前为前端布局与本地状态。

## 依赖关系

- 依赖：`src/components/ui/`、`src/context/`、`src/stores/auth-store.ts`、`src/lib/cookies.ts`。
- 被依赖：所有 `_authenticated` 下的后台页面。
- 导航数据：`src/components/layout/data/sidebar-data.ts` 是侧边栏入口数据源。

## 影响范围

修改布局会影响所有登录后页面，包括仪表盘、设置中心和后续业务模块。修改侧边栏数据会影响导航入口、全局命令搜索可见性和用户访问路径。

## 修改边界

- 可以改：布局组件内部展示、导航数据、菜单分组、顶部栏组合、响应式细节。
- 绝对不能动：无需求不得改变 `_authenticated` 路由结构、主题/字体/方向 Provider 的装配顺序、基础 shadcn/ui 组件实现。

## 注意事项

- 当前 `_authenticated` 只是布局分组，尚未形成完整真实鉴权守卫。
- `_authenticated` 当前已接入本地会话守卫，但不代表真实服务端权限控制。
- 侧边栏和部分 UI 组件包含 RTL/项目定制，更新 shadcn 组件时需要人工合并。
- 内部工作台不展示付费升级、账单、新建团队、添加团队等 SaaS 模板入口。
- 新增导航入口时，需要同步检查路由文件和责任田文档。

## 约束

- 必须复用：`AuthenticatedLayout`、`Header`、`Main`、`AppSidebar`、`Search`、`ThemeSwitch`、`ProfileDropdown`。
- 验证要求：布局代码修改后运行 `pnpm run lint`、`pnpm run build`，必要时检查桌面和移动端布局。
