# 责任田：快捷导航

## 功能描述

提供内部系统、工具和知识文档的分类导航、搜索与管理员维护能力。

## 功能清单

- 登录用户浏览置顶链接和分类导航卡片。
- 按分类名称、导航名称、说明和标签搜索。
- 管理员维护分类、导航项、多个标签及显示顺序。
- 参考页中的 3 个置顶入口、6 个分类、13 个导航项和 22 个标签由数据库初始化脚本幂等导入。

## 入口与出口

- 浏览入口：`/quick-navigation`。
- 管理入口：`/quick-navigation/manage`。
- 服务端入口：`/api/quick-navigation` 及导航管理接口。

## API 明细

- `GET /api/quick-navigation`：登录用户读取置顶入口、分类导航与全部标签。
- `POST/PATCH/DELETE /api/navigation-categories`：管理员维护分类；非空分类禁止删除。
- `POST/PATCH/DELETE /api/navigation-items`：管理员维护导航项及标签关联。
- `POST/PATCH/DELETE /api/navigation-tags`：管理员维护标签；删除标签时解除导航关联。

## 数据模型

- `navigation_categories`：分类名称和显示顺序。
- `navigation_items`：名称、链接、说明、展示位置、分类和显示顺序。
- `navigation_tags`：可复用标签。
- `navigation_item_tags`：导航项与标签的多对多关联及标签顺序。
- `schema_migrations`：记录已应用的快捷导航数据库迁移版本。

## 依赖关系

- 依赖：认证状态、React Query、PostgreSQL、全局布局和主题变量。
- 被依赖：侧边栏快捷导航入口。

## 影响范围

新增独立业务模块及数据库表，不改变仪表盘快捷方式偏好数据。

## 数据库升级

- API 启动前自动执行 `server/navigation-migrations.mjs` 中尚未应用的迁移，迁移失败时服务不会监听端口。
- `pnpm run db:setup` 复用同一迁移入口。
- 初始化数据以版本化迁移逐条非破坏写入，管理员后续修改不会被重复启动覆盖。

## 修改边界

- 可以改：快捷导航页面、管理界面、导航数据 API 与专属数据库表。
- 绝对不能改：现有仪表盘快捷方式语义和用户角色定义。
