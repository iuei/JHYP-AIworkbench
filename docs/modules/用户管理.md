# 责任田：用户管理

负责管理员查询、筛选、创建、编辑、停用账号和重置密码的内部账号管理。姓名、部门、角色都由这里配置，用户侧只读。

## 边界与接口

- 页面路由：`/_authenticated/settings/users`
- 仅数据库中实时角色为 `admin` 且状态为 `enabled` 的用户可访问和操作。
- 查询与角色、状态筛选在前端基于当前用户列表组合执行。
- 接口：`GET/POST /api/users`、`PATCH /api/users/:id`、`PATCH /api/users/:id/status`、`POST /api/users/:id/reset-password`。
- 编辑接口仅允许修改姓名、部门和角色；管理员不能修改自己的角色或账号状态。
- 角色降级和账号停用都会保护最后一个已启用管理员。
- 角色中文文案由 `src/features/settings/user-labels.ts` 统一提供，与用户信息页共用。

## 部门字段

- 落库在 `users.department VARCHAR(40) NOT NULL DEFAULT ''`，由迁移 `server/user-migrations.mjs` version 2 添加。
- 开通账号时可选填；编辑时可修改或清空（提交空串即清空）。
- `parseUserUpdate` 对未携带 `department` 的请求返回 `null`，SQL 用 `COALESCE($3, department)` 保留原值 —— 老调用方不会把已有部门静默清空。
- 用户信息页通过 `GET /api/auth/me` 只读展示该字段；新增或改名时必须同步该接口的 SELECT 与 `src/features/settings/profile/types.ts`。
