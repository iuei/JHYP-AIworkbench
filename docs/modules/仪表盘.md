# 责任田：仪表盘

## 功能描述

负责后台首页的内部工作台入口、业务模块占位和真实数据接入前的空态说明。

## 功能清单

- 首页入口：展示智能工作台基础说明。
- 模块占位：提示后续可接入业务模块、待办中心、权限体系和系统设置。
- 空态说明：明确当前不展示伪业务指标，避免误读为真实数据。

## 入口与出口

- 入口：`src/routes/_authenticated/index.tsx`。
- 出口：当前无业务跳转出口，主要作为登录后首页展示。

## API 明细

- 暂无真实 API，当前不展示经营、销售或订阅类演示数据。

## 依赖关系

- 依赖：`src/components/layout/`、`src/components/ui/`。
- 被依赖：全局首页路由和后台默认入口。
- 共享字段：当前无跨模块写入字段。

## 影响范围

修改仪表盘可能影响首页首屏信息结构、主题适配和移动端布局。后续接入真实数据时会影响 API 层、React Query 查询键和错误处理。

## 修改边界

- 可以改：仪表盘内部卡片、业务占位、空态和加载态。
- 绝对不能动：无需求不得修改全局布局、认证路由分组、主题变量命名和其他模块页面结构。

## 注意事项

- 当前是内部工作台首页，不展示模板销售、收入、订阅等伪数据。
- 后续接 API 前应先建立 `src/api` 模块和查询约定。

## 约束

- 必须复用：`Header`、`Main`、shadcn/ui Card。
- 验证要求：代码修改后运行 `pnpm run lint`、`pnpm run build`。
