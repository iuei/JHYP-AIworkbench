### 9.3 真实模型暴露并修复的 3 个缺陷

| 现象 | 根因 | 影响 | 修复 |
| --- | --- | --- | --- |
| **问"你好"等不调工具的问题，回答被替换成「AI 服务暂不可用」** | `answer` 只在工具循环内赋值；模型不调工具直接作答时（问候语、无需检索的判断）回答被丢弃 | 高危：正常回答变错误提示，且审计误记为 error | 用第一轮返回的内容初始化 `answer`；循环内改为"有新内容才覆盖"；新增回归测试 |
| **答案流式显示完就消失** | `refresh()` 用 `send` 闭包里的 `activeId`，新会话时它是 `null`，于是真正落库的会话从未被重新拉取 | 高危：用户看到答案闪一下就不见了（演示模式响应极快，碰巧晚于落库，掩盖了这个竞态） | 新增 `conversationIdRef` 记录本次请求实际使用的会话，刷新以它为准；副作用移出 `setState` updater |
| **越权拦截未记录（拦截率 0%）** | 模型按提示词直接输出了统一文案，行为正确，但编排层只在"主动替换文案"时才记 blocked，导致审计缺失 | 中：A5 要求"拦截并记录"，缺记录等于没证据 | `enforcePermissionWording` 增加 `canonical` 判定与"自述式拒绝"识别，两种情况都写 `tool_blocked` 审计 |

### 10.4 服务端分析的可复核性

以"ACoS 为什么涨了"为例，服务端分解结果：总变化 **+11.93 个百分点** = 花费效应 **+4.81** + 销售额效应 **+7.12**，**残差 0**；主因 = 广告销售额变化。模型回答直接引用了这三个数字，未自行重算或改写，并补充了"CPC +27.45%、转化率 12%→9.46%"的传导链条（同样来自服务端对比数据）。

### 10.5 本轮修复的缺陷

### 10.6 一个环境观察（非产品缺陷）

`index.html` 从 `fonts.googleapis.com` 加载 Inter / Manrope 字体。当前网络下 `fonts.gstatic.com` 不可达，
浏览器会打 `net::ERR_CONNECTION_CLOSED`。这不影响功能（回退到系统字体），但：

- UI 冒烟脚本原先会因此判失败，已改为**按请求来源判定**：应用自身来源（5173 / 8787）的请求不允许失败，
  外部 CDN 失败单独列出、不计入失败（输出里可见，不隐藏）；
- **建议内网部署前把字体改为自托管**，否则员工看到的字体与设计稿不一致（离线环境下更明显）。

### 11.2 一个必须记录的安全修复

实测采样发现：普通用户请求管理类操作时，模型 **4 次里有 3 次会把自己的可用工具清单念出来**：

> "我无法执行这个操作。原因：我这次可用的工具只有知识库检索、Amazon 广告/销售表现查询、库存与订单查询、库存风险分析、广告异常扫描这几类，没有文档上下线/发布状态管理的能力。"

这等于给越权用户一个**权限探测探针**，违反 PRD §5.1「不泄露权限结构」。
修复：`enforcePermissionWording` 的模式表用真实回答固化（容忍"我…具备…能力"插入语），同义变体统一规整为固定文案。
修复后同一问题采样 4/4 全部返回固定文案且 `status=blocked` 并写入 `tool_blocked` 审计。

### 11.3 本轮修复的缺陷汇总

| 现象 | 根因 | 修复 |
| --- | --- | --- |

## 十三、本轮实测发现并修复的缺陷

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 所有工具对所有人「不可用」，连管理员也被拦截 | `requireUser` 只下发 `id/login/role`，权限层依赖的 `status` 缺失，`isEnabledUser` 恒为 false | `requireUser` 补下发 `status`；AI 路由再加一层 `identityGuard` 每请求回源校验角色与状态，不依赖 JWT 旧值 |
| 按文档标题提问检索不到内容 | 检索只匹配 `ai_chunks.content`，标题里的关键词不在正文中 | 关键词命中同时计入 `ai_documents.title` |
| 上传中文文件名请求直接失败 | HTTP 头不允许非 ASCII 字符 | 前端 `encodeURIComponent`，服务端容错 `decodeURIComponent` |
| 枚举参数（如 `sourceType`）非法值被放过 | 参数校验里字符串分支提前 `continue`，跳过了枚举判断 | 枚举与数值范围判断提到类型分支之前 |
| 已落库回答不显示工具轨迹 | `ai_runs` 挂在提问消息上，展示时未归到回答 | `listMessages` 按轮次归位工具轨迹 |
| 窄屏无法访问历史会话 | 左栏 `lg:flex` 直接隐藏，无替代入口 | 新增左侧会话抽屉 |
| **问知识库中不存在的制度也会"检索到内容"** | 检索只判断"关键词命中数 > 0"，而中文双字切分下「公司」「规定」几乎每篇文档都有 | 引入相关性下限 `MIN_QUERY_COVERAGE = 0.2`（按实测标定），负样本正确声明率从 0% 提升到 100% |
| 检索评测失真 | 验收脚本每跑一次新增两份近似重复文档，累积污染语料 | `verify-e2e.mjs` 改为按 `source_ref` 复用文档；新增 `clean-test-docs.mjs` 清理历史污染 |
