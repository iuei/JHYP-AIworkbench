# 统一用户信息入口设计

## 目标

取消左侧栏底部用户信息与顶部头像的下拉菜单，两个入口均直接跳转 `/settings`。将个人资料、账户信息和退出登录整合到同一用户信息页面。

## 交互设计

- 左侧栏底部用户信息改为普通路由链接，不再响应点击或悬停弹出菜单。
- 顶部头像改为普通路由链接，不再展示个人资料、设置或退出登录菜单。
- `/settings` 依次展示用户概览、个人资料、账户信息、登录与安全。
- `/settings` 在桌面端使用个人资料与账户信息双栏布局，登录与安全横跨底部；移动端回落为单列。
- 设置路由壳不显示固定的“设置”标题，由用户信息、用户管理、外观等子页面各自提供唯一页面标题，避免重复层级。
- 退出登录仍通过现有 `SignOutDialog` 二次确认。
- `/settings/account` 自动重定向到 `/settings`，保持旧链接兼容。
- 全局侧边栏“设置”下移除重复的“个人资料”和“账户”入口，保留用户管理和外观。

## 技术边界

- 复用现有 `Header`、`Main`、`ContentSection`、`ProfileForm`、`AccountForm`、`SignOutDialog` 和主题变量。
- 不修改认证状态模型、退出登录逻辑、服务端接口或基础 shadcn/ui 组件。
- 保持桌面端、移动端和折叠侧边栏可访问性。

## 验收标准

- 点击左侧栏底部用户区域直接进入 `/settings`，不出现菜单。
- 点击顶部头像直接进入 `/settings`，不出现菜单。
- `/settings` 同时显示个人资料、账户信息和退出登录操作。
- 退出登录必须二次确认。
- `/settings/account` 跳转 `/settings`。
- lint、构建和相关浏览器测试通过。
