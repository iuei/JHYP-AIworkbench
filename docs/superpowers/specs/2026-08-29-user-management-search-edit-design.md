# 用户管理查询筛选与编辑设计

## 目标

- 在用户管理页按姓名或登录账号即时查询用户。
- 支持角色、状态组合筛选与一键重置。
- 在操作列编辑用户姓名和角色；登录账号只读。

## 交互设计

- 表格上方使用单行工具栏，窄屏自动换行。
- 查询框匹配姓名和登录账号，不区分大小写。
- 角色筛选包含全部、管理员、普通运营人员；状态筛选包含全部、已启用、已停用。
- 查询、角色、状态可组合使用；没有结果时在表格内显示空状态。
- 编辑弹窗展示只读登录账号，仅允许修改姓名和角色，保存后刷新列表。

## 接口与安全

- 新增管理员接口 `PATCH /api/users/:id`，请求体仅接受 `name`、`role`。
- 姓名去除首尾空白后不能为空，角色仅允许 `admin`、`operator`。
- 禁止将最后一个已启用管理员降级，返回 409 和明确提示。
- 管理员鉴权以数据库中的实时角色和状态为准，避免角色变更后旧令牌继续保留管理权限。

## 影响范围

- 用户管理前端页面及其纯筛选逻辑。
- 用户管理后端接口和管理员鉴权中间件。
- 用户管理责任田文档与相关测试。
