# 顶部布局统一交接摘要

- **最后更新**：2026-09-22
- **范围**：全局 Header、页面标题、面包屑、模块内导航和内容宽度
- **责任田**：[全局布局与导航](/Users/lzg/codex/codex项目文件/JHYP-AIworkbench-main/docs/modules/全局布局与导航.md)

## 目标

全站只保留一个统一顶栏，减少页面重复标题和顶部空白，让页面标题、同级导航、搜索、主题和用户入口位置一致。

## 当前规则

- `AuthenticatedLayout` 只渲染一次 Header。
- 页面标题由路由 `staticData.title` 和面包屑规则生成。
- 页面内容区不再重复渲染大标题横幅。
- AI 助手、AI 治理等模块导航通过 Header 中段注入。
- 主内容默认 `max-w-[1280px]` 居中。
- 顶栏固定高度 64px，页面应避免横向滚动。
- 页面级 Tabs、模块级导航和页签栏职责分开，不能互相替代。

## 验证状态

已完成构建、lint、服务端测试和主要布局场景验证。重点覆盖：

- AI 助手三栏布局。
- 1280px、1024px 和 390px 宽度。
- 侧边栏折叠后顶栏与内容边界同步。
- Header sticky、内容滚动和暗色模式。
- 页面只有一个主标题，不出现重复标题横幅。

## 当前限制

- 不同模块的滚动模型仍有差异：部分页面整页滚动，部分页面内容区内部滚动。
- 整页滚动页面的 sticky 顶栏可能出现少量顶部位移。
- 顶部头像和侧边栏底部用户信息的真实用户接入属于独立任务。
- AI 治理说明文字已按需求收敛；如需恢复，应放进页面说明或 tooltip，不要重新增加顶部标题区。

## 验证命令

```bash
pnpm run lint
pnpm run build

```

新增页面时必须复用现有 Header/Main 布局；不要在业务页面重新实现一套顶部布局。
