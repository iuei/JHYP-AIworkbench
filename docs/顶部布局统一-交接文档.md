## 任务目标

需求方原话：*「所有页面顶部设计都不合理，留空留白太多」*，进一步澄清为：

> 顶部有一个搜索框，还有「JHYP 智能工作台 / 用 AI 与自动化加速跨境电商运营工作。」这两段文本，占了**三行**，而且文本还是 H1/H2 —— **这些内容并不是重点，不需要那么显眼占用那么多空间。且中间都是空白没有任何内容。**快捷导航、我的沉淀也是一样的问题。

## 已确认的方案（用户三选一，均按选项执行）

1. **T1+T2+T3 全量**：页面名统一进 Header（`text-sm font-medium`），内容区彻底移除标题横幅；Header 只渲染一次（标题来自路由 `staticData`）；间距收敛。
2. **描述文字全部删掉**（含 AI 治理页原有 7 条说明文案）。
3. **T4 做**：AI 治理 / AI 助手的模块内二级导航移进 Header 中段。
4. 另按需求方明确的「水平」诉求（原话选项：*「Header 中间 992px 全空、内容铺到 1392px 无边距感」*）给 `Main` 加统一最大宽度并居中。

## 踩过的坑

| 现象 | 根因 | 规避方式 |
| --- | --- | --- |
| **顶栏被压扁到 37px，量测数字反而"更好看"，差点误判优化成功** | `SidebarInset` 是 flex 纵向容器，`h-16` 只提供 flex-basis，内容区一高（AI 治理长页面）就把顶栏挤到 min-content 高度 | 顶栏必须 `h-16 shrink-0`。**教训：布局改动后不要只看"留白变少了"，要同时断言关键元素自身的尺寸**（`header height === 64`） |
| 页面首个内容 top 出现 61/70/79 这种低于 Header 底部的怪值 | 同上，Header 被压缩导致下方所有元素整体上移 | 量测脚本里对"Header 高度"单独设断言，异常值先诊断再下结论 |
| React Fast Refresh 报 `only-export-components` | 同一文件既导出 Provider/组件又导出 hook | context + hook 拆到 `header-slot-context.ts`，`.tsx` 只留组件 |
| 测试里 mock 的 `@/components/layout/header` 变成了无声的死 mock | 页面已不再 import Header，`vi.mock` 不会报错，只是永不生效 | 删除组件引用时同步清理 mock，否则后人会以为该页面还在渲染顶栏 |
| 临时 vitest 配置写不进去：`file no longer exists — re-read the file, then retry` | 同名文件被删除后，写工具的观测状态与磁盘不一致 | 换一个文件名，或用 shell（`cat > file <<'EOF'`）创建这个一次性文件 |
| 量测脚本放 `/tmp` 里跑不起来：`Cannot find package 'dotenv'` | Node 按脚本所在目录向上找 `node_modules` | 临时脚本必须放在工作区内（本次放 `verify-artifacts/`，用完删除） |
| `sticky top-0` 断言写成 `headerTop === 8` 一直失败 | inset 布局滚动前 Header top=8，sticky 生效后贴到 0，是**正确**行为 | 断言写成"未滚动时 8 / 滚动后 ≤ 8"；区分"内部滚动"与"整页滚动"两种场景 |
| 暗色模式检查失败，`isDark: false` | `ThemeSwitch` 是 DropdownMenu，点触发器只开菜单，还要点「深色」 | UI 脚本里先 `getByRole('button')` 再 `getByRole('menuitem', { name: '深色' })` |
| `useMatches` 类型扩展写在 `@tanstack/react-router` 还是 `@tanstack/router-core` | `StaticDataRouteOption` 定义在 router-core，react-router 只是 re-export | 本次按 `@tanstack/react-router` 声明合并即生效（`tsc` 已通过）；如遇不生效再改到 router-core |
| 给 `Main` 加 `max-w` 与 2026-07-09 的历史决策相反 | 历史条目明确写过「取消主内容区宽屏最大宽度限制」 | 已在 `docs/modules/全局布局与导航.md` 的历史变更里**显式记录这次反转及理由**，避免后人反复来回改 |
