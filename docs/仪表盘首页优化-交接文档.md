## 目标与现状

首页定位为个人工作台：进入真实业务、继续未完成工作、查看最近活动。不展示伪功能卡片，也不展示 AI 治理内容。

当前首页包含：

- 可排序的真实业务入口。
- 工作项和最近分析。
- 加载、空态、失败重试状态。
- 桌面端分栏和移动端单列布局。

## 主要实现

- 快捷入口契约集中在 `src/features/dashboard/shortcuts.ts`。
- 首页组件位于 `src/features/dashboard/index.tsx`。
- 首页 API 仍由 `/api/dashboard` 提供。
- 排序支持拖拽和键盘按钮，保存失败时保留用户当前顺序。
- 卡片使用统一最小高度和 `min-w-0`，避免窄屏横向滚动。

## 验证状态

已完成构建、lint、服务端测试和首页浏览器验证。历史测试项数会随仓库变化，不在本文档固化具体数字。

重点验收：

- 桌面 1440px/1024px 与移动 390px 布局正常。
- 长标题不产生页面横向滚动。
- 排序按钮首尾状态正确。
- 查询失败可以重新加载。
- 不出现“即将上线”或 AI 治理占位内容。

## 当前限制

- 最近活动仍以竞品分析为主，扩展其他活动时应新增独立 API 字段。
- `/api/dashboard/shortcuts` 的顺序归一化主要在前端，若未来增加其他客户端写入，需要补服务端校验。
- 认证布局测试仍有历史的品牌文案定位冲突，和本页面改造无关。
