# 用户信息只读化交接摘要

- **最后更新**：2026-09-22
- **页面**：`/settings`
- **责任田**：[设置中心](/Users/lzg/codex/codex项目文件/JHYP-AIworkbench-main/docs/modules/设置中心.md)、[用户管理](/Users/lzg/codex/codex项目文件/JHYP-AIworkbench-main/docs/modules/用户管理.md)

## 目标

用户侧只展示登录账号、姓名、部门和角色，并提供退出登录。姓名、部门和角色由管理员在用户管理页面维护，用户侧不再提供不会落库的演示表单。

## 已完成内容

- `/settings` 通过 `GET /api/auth/me` 读取当前用户信息。
- 删除个人资料和账户信息两个假表单。
- `users.department` 已加入数据库和管理员创建/编辑流程。
- 用户管理列表增加部门字段。
- 空部门显示“未设置”，请求失败显示可理解的错误状态。
- 保留退出登录，不新增自助改密码功能。

## 数据与权限

- 用户只能读取自己的 `/api/auth/me` 信息。
- 姓名、部门、角色的写入路径是管理员用户管理接口。
- 不允许在用户侧修改 `role`、`login` 或权限相关字段。
- 缺少 `department` 的旧 PATCH 请求不会覆盖已有部门；显式传空值才表示清空。

## 当前限制

- 自助修改密码尚未实现，忘记密码由管理员重置。
- 顶部头像和侧边栏底部用户区仍需继续统一为真实用户信息时，应单独修改全局布局责任田。
- 认证布局测试存在与本任务无关的品牌文案定位冲突。
