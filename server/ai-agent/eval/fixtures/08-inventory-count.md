# 仓库盘点与库存差异处理

## 盘点频次

- 月度全盘：每月最后一个完整周，覆盖全部在库 SKU
- 周度抽盘：每周五，抽取上月有差异的 SKU 与高价值 SKU
- 临时盘点：发生大批量退货、仓库搬迁、系统数据异常时

## 盘点流程

1. 盘点前冻结系统出入库操作，导出系统库存明细
2. 按库位逐箱清点，记录实盘数量、库位、批次
3. 计算差异：差异数 = 实盘数 - 系统数
4. 差异率超过 1% 或差异数量超过 20 件时，必须二次复核
5. 复核确认后填写《库存差异报告》，说明原因并附证据（照片、交接记录）
6. 财务与仓储负责人签字后调整系统库存

## 差异原因分类

- 收发货登记错误（最常见）
- 退货未及时入库
- 库位串货或标签脱落
- 破损报废未登记
- 系统同步延迟

## 差异责任

盘盈不做处罚；盘亏按差异金额分档处理，单次差异金额超过 500 元需提交书面说明。连续两个月同一 SKU 出现差异的，由仓储主管牵头做流程复盘。

## 常见问题

- 盘点未冻结操作，边盘边动导致差异无法定位
- 差异报告只写数量不写原因，无法改进
- 只做月度全盘不做周度抽盘，问题发现滞后
