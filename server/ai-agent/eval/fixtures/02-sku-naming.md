# SKU 命名与图片规范

## SKU 命名规则

SKU 由「品类代码 + 品牌缩写 + 系列号 + 变体代码」四段组成，用短横线连接，全部使用大写字母与数字。

- 品类代码：厨房小家电为 KT，户外用品为 OD，家居收纳为 HM
- 品牌缩写：2-4 位大写字母，与商标注册主体一致
- 系列号：3 位数字，按立项顺序递增
- 变体代码：颜色用 2 位字母（BK 黑、WH 白、RD 红），尺寸用 S/M/L

示例：`KT-JH-001-BK` 表示厨房小家电、JH 品牌、第 1 个系列、黑色变体。

## 禁止事项

- 禁止在 SKU 中使用中文、空格、下划线
- 禁止重复使用已停售产品的系列号
- 禁止把颜色写进系列号位置

## 图片规范

- 首图必须为纯白背景，产品占比不低于 85%，不得出现文字、水印、logo
- 场景图至少 3 张，展示真实使用场景，不得使用明显的合成素材
- 尺寸图需标注英寸与厘米双单位
- 主图分辨率不低于 1600×1600 像素，支持放大镜功能
- 所有图片不得出现其他品牌 logo 或侵权元素

## 命名变更

已上架产品的 SKU 不允许变更；如需更名，必须新建 SKU 并在后台做映射，同时在飞书「产品变更记录」中登记。
