# 备货报关方式区分及要求

## 两种报关方式的区别

**一般贸易报关**：适用于有正规采购发票、可提供完整报关资料的备货。需要提供合同、发票、装箱单、报关委托书。退税可正常办理。

**买单报关（无票报关）**：适用于供应商无法开具增值税专用发票的情况。不能办理退税，且存在合规风险，需经财务与运营负责人共同审批后方可使用。

## 选择判断标准

1. 供应商能开具增值税专用发票 → 走一般贸易报关
2. 供应商为小规模纳税人、只能开普票 → 需评估退税损失后再定
3. 首次合作的新供应商 → 必须先完成供应商资质审核

## 报关资料准备要求

- 中文品名与 HS 编码必须与实际货物一致，不得归入模糊编码
- 申报价值需与采购发票金额一致，差异超过 5% 需说明原因
- 装箱单需列明每箱的 SKU、数量、毛重、净重、箱规
- 涉及品牌的产品必须提供商标注册证或授权书

## 时效要求

报关资料需在货物入仓前 3 个工作日提交给物流专员，逾期导致甩柜的，责任由提报人所在部门承担。

## 常见问题

- HS 编码归类错误导致查验扣货，平均延误 5-10 天
- 装箱单毛重与实测不符，产生改单费用
- 品牌授权过期未更新，货物被扣
