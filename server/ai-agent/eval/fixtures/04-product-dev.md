# 新品开发流程（产品开发系统 v1.0）

## 全流程节点

1. **需求收集**：通过飞书「新品开发需求收集表单」提报，需填写目标市场、价格带、竞品链接、预估月销量。
2. **立项评审**：每周二下午评审会，由产品负责人、运营负责人、供应链三方确认是否立项。未通过的需求需在表单中记录驳回原因。
3. **选品调研**：立项后 5 个工作日内完成竞品分析，输出价格带分布、评论痛点、专利风险初筛。
4. **专利与商标排查**：必须在打样前完成。美国商标查询用 USPTO，欧盟用 EUIPO，专利可用智慧芽或睿观查；排查结论必须留档。
5. **打样与验样**：供应商提供样品后由产品负责人验样，重点核对尺寸、材质、包装、说明书。
6. **试单**：首批试单量不超过 300 件，用于验证转化率与退货率。
7. **正式备货**：试单数据达标（转化率 ≥ 8%，退货率 ≤ 5%）后进入正式备货。

## 各节点时效要求

| 节点 | 时效 |
| --- | --- |
| 需求评审 | 每周二固定 |
| 选品调研 | 立项后 5 个工作日 |
| 专利商标排查 | 打样前完成 |
| 打样 | 供应商确认后 10-15 天 |
| 试单验证 | 上架后 30 天 |

## 开发系统登记要求

所有节点必须在产品开发系统中更新状态，未登记视为节点未完成。需求完成度低于 95% 的不允许进入试单阶段。

## 常见问题

- 跳过专利排查直接打样，上架后被投诉下架
- 试单量过大导致库存积压，建议不超过 300 件
- 说明书未做目标市场语言版本，产生客诉
