# 广告 ACoS 异常归因方法

## 归因排查顺序

按以下顺序逐项排查，先排除外部因素再定位内部因素：

1. **竞价环境**：查看建议竞价是否上涨，竞品是否新增投放。竞价整体上涨 20% 以上时，ACoS 上涨属于行业性变化。
2. **转化率**：对比近 7 天与上月同期转化率。转化率下降是 ACoS 上涨最常见的原因。
3. **Listing 质量**：检查主图、标题、A+ 页面是否被改动；差评是否增加；库存是否显示为「暂时缺货」。
4. **广告结构**：检查是否有新增低效关键词或自动活动扩量导致花费上升。
5. **价格与促销**：对比价格变化与促销结束时间。价格上调 5% 以上通常带来转化率下降。
6. **季节性**：对比去年同期表现，排除季节因素。

## 判定标准

| 指标 | 正常范围 | 预警线 |
| --- | --- | --- |
| ACoS | 20%-30% | 高于 35% |
| 转化率 | ≥ 10% | 低于 7% |
| 点击率 | ≥ 0.4% | 低于 0.25% |
| 广告订单占比 | 40%-60% | 高于 75% |

## 处理动作

- ACoS 高于预警线且转化率下降 → 优先优化 Listing 与价格，暂停低效关键词
- ACoS 高于预警线但转化率正常 → 降低竞价 10%-15%，观察 3 天
- 广告订单占比高于 75% → 检查自然排名是否下滑，补充站外与促销

## 数据要求

归因必须基于同一站点、同一 ASIN 的广告报表与业务报告对比，**同比对比使用去年同期同月份数据**。数据来自人工导出的报表，非实时数据，结论需标注数据截至日期。

## 常见问题

- 只看 ACoS 不看转化率，误判为竞价问题
- 未排除季节因素，把季节性波动当成广告问题
- 用不足 7 天的数据下结论，样本量不够
